# 首页表达与入口调整 · 2026-09-22

目标：首次来访者先理解能探索什么、需要什么输入、会得到什么，再进入日柱、情感匹配或抽签。保留东方玄学、BaZi 与 Chinese fortune sticks 等清楚的来源名称。

## 本次改动

- 首页主标题与导语改成自我认识、关系和选择三个生活主题。
- 原来的三步生日展示条替换成三个可点击入口。每个入口包含具体情境、结果说明、输入要求和行动按钮；手机单列。
- 首页匹配区从动物名开场改为“想被安慰／急着解决问题”的场景，再交代八字五行、动物意象和星盘。
- 首页及抽签页解释带什么问题、会收到什么；保留静心、签堂和求签仪式的表达。
- 新增信仰／文化／个人判断的简短说明，展开后区分历法与天体计算、传统解释、原创动物卡、随机抽签和可选AI解签。
- 英、简、繁、俄同步；首页搜索标题和描述相应更新。既有路由、canonical与语言索引范围保持原有规则。

## 表述依据

`components/spiritual-sticks-experience.tsx` 以浏览器 `crypto.getRandomValues` 选签，再调用签库；AI解释为另一步。`lib/compatibility/copy.ts` 已解释60–100指数为编辑尺度。程序没有检测未来信息或跨维度信号的能力说明或验证记录，因此本次不把此类信念写成科学结论，也不以恐惧或保证结果促使付款。

## 验证

- 生产构建通过。
- 原有SEO和指南14项测试通过；只更新因新标题/描述而变化的两处断言。
- 本地首页、抽签、匹配四语言共12个URL返回200、单一H1、canonical正确；首页新引导文本在初始HTML可见。
- 中文桌面入口检查；中文与俄文320px无水平溢出；说明可展开，入口跳转保留俄文语言参数。
- 这次没有测试AI服务响应、收费或账户流程，没有改变算法和支付逻辑。

## 后续观察

本次是待验证的产品表达假设，不宣称能立即提升搜索排名。沿用已授权周一复盘，记录发布日期后完整七天窗口的首页、/discover、/sticks、/compatibility访问及可取得的工具事件；GSC只使用已返回日期。若无法取得同一访客的首页到工具链路，不用聚合工具事件除以首页访客冒充转化率。现有tool_open会记录这些内容区链接，不能据此声称已单独识别本组三张卡的效果。优先修订已有落地页，不用新增文章篇数代替增长结果。第三方推广尚未发布。
